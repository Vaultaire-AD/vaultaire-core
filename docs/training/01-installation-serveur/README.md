# Chapitre 1 — Installer le serveur

[← Sommaire de la formation](../README.md) · [Chapitre 2 — Premiers groupes et utilisateurs →](../02-groupes-et-utilisateurs/README.md)

---

Mettre en route un serveur Vaultaire complet — core, base MariaDB, Keycloak —
à partir de la dernière release, puis s'y connecter et le sécuriser.

## Prérequis

- une machine Linux (VM ou physique) avec **Docker ≥ 24** et le plugin `compose` ;
- `git` et `curl` ;
- 2 Go de RAM libres, les ports du tableau ci-dessous disponibles.
