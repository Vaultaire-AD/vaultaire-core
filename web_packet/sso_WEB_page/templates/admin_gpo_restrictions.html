Domaines de valeurs par champ

Chaque champ a un mode. En mode liste, seules les valeurs énumérées passent — c'est là qu'on déclare un service maison ou un paquet interne. En mode motif, toute valeur conforme à l'expression régulière est acceptée, ce qui évite d'énumérer une famille entière. Le motif d'exclusion est prioritaire dans tous les modes : il permet d'ouvrir largement tout en gardant des refus fermes.

Emplacements de fichiers refusés

Un chemin dont le début correspond à l'un de ces préfixes est refusé, quelle que soit la GPO. Le refus est prioritaire sur toute autorisation. Portée any = les deux scopes.

{{ template "restriction_rows" .PathDeny }}

Emplacements de fichiers autorisés

Si au moins une autorisation existe pour un scope, la validation devient une liste blanche pour ce scope : tout chemin hors de ces préfixes est refusé. Aucune autorisation = pas de contrainte d'emplacement au-delà des refus ci-dessus. Le marqueur {{ .HomeMarker }} est remplacé par l'agent par le home réel de l'utilisateur cible.

{{ template "restriction_rows" .PathAllow }}

Variables d'environnement interdites

Variables qu'une GPO utilisateur ne peut pas définir. Celles du socle par défaut permettent toutes de détourner l'exécution d'un binaire quelconque (injection de bibliothèque, substitution d'interpréteur, redirection de la résolution de commandes).
