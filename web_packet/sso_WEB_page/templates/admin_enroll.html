Émettre une clé

Un client service — interface web, proxy, extension — génère sa paire de clés sur son propre hôte et présente une clé d'enrôlement pour faire enregistrer sa clé publique. Sa clé privée ne voyage jamais.

Le type est porté par la clé, pas déclaré par le service. Sans cela, il suffirait de s'enrôler pour se donner les privilèges qu'on veut.

{{ if .CanCreate }}

0 = illimité.

0 = sans expiration.

⚠ Une clé sans limite ne s'éteint que par révocation. À réserver aux chaînes de déploiement qui recréent des services sans intervention humaine.

Émettre une clé pour un type capable d'agir au nom d'un utilisateur est réservé au groupe d'amorçage. {{ if not .IsSuperadmin }}Vous n'en faites pas partie.{{ end }}
