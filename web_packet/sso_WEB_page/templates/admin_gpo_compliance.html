« non vérifié » n'est pas « conforme ». Une machine que personne n'a scannée affiche zéro écart parce que rien n'a été regardé. De même, une machine muette figure dans la vue des écarts : ne pas savoir est le cas qu'on veut le moins cacher.

Le même état en ligne de commande : vlt gpo status, vlt gpo drift, vlt gpo status <computeur_id>.
