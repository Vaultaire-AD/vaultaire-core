Ce que l'expiration change

CheminMot de passe expiré
Bind LDAPrefusé
Client Ducky / PAMrefusé, avec un message explicite
Interface webconnexion acceptée, mais seule la page de changement de mot de passe est accessible

L'interface web reste ouverte à dessein : c'est le seul endroit où l'utilisateur peut changer son mot de passe. La fermer aussi transformerait chaque expiration en demande au support.

Le compte d'amorçage vaultaire n'est pas concerné par l'expiration : c'est le compte de dernier recours. Il doit être traité comme un secret d'infrastructure — changé à l'installation, conservé hors ligne, non utilisé au quotidien.

Second facteur

L'exigence de second facteur se règle par groupe, sur la page de chaque groupe. Un utilisateur y est soumis dès qu'un de ses groupes l'exige.

La réinitialisation du second facteur d'un compte — téléphone perdu — demande le droit write:mfa, distinct de write:update:user.
